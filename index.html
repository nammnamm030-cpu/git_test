프로그래밍 핵심 개념 5가지 실습

변수 · 조건문 · 반복문 · 함수 · 데이터 타입, 5가지 개념을 직접 눌러보면서 익혀봅니다.

01. 변수 (Variable): 데이터 담기

데이터를 저장해두는 '상자'입니다. 사용자의 아이디, 장바구니에 담긴 상품의 총액, 현재 시간 등 프로그램이 실행되는 동안 기억하고 조작해야 하는 정보들을 담아둡니다.

const userId = "haewa_2026";      // 문자열을 담는 변수
const price = 4500;               // 숫자를 담는 변수
const quantity = 2;
const total = price * quantity;   // 변수끼리 계산해서 새 값 만들기



여기에 결과가 표시됩니다.

02. 조건문 (if): 분기

주어진 상황에 따라 프로그램의 흐름을 나누는 갈래길입니다. "비밀번호가 일치하면 로그인을 승인하고, 틀리면 에러 메시지를 띄운다"처럼 논리적인 판단을 내릴 때 사용합니다.

if (inputPassword === correctPassword) {
    // 조건이 참(true)일 때 실행
    console.log("로그인 성공");
} else {
    // 조건이 거짓(false)일 때 실행
    console.log("비밀번호가 틀렸습니다");
}

테스트용 정답 비밀번호는 1234 입니다.

결과가 여기에 표시됩니다.

03. 반복문 (loop): 반복

단순하고 반복적인 작업을 컴퓨터가 빠르게 처리하도록 지시합니다. 게시판의 글 목록을 화면에 순서대로 나열할 때처럼 필수적으로 사용됩니다.

for (let i = 1; i <= count; i++) {
    // count번 만큼 반복 실행되는 코드
    console.log(i + "번째 게시글");
}

    04. 함수 (Function): 묶기

    특정 목적을 위한 코드 여러 줄을 하나로 묶어 이름을 붙여둔 '명령어 세트'입니다. '결제 처리' 함수를 한 번 만들어두면, 필요할 때마다 코드를 다시 짤 필요 없이 그 블록만 불러와서 재사용할 수 있습니다.

    function processPayment(itemName, amount) {
    // 이 블록 안의 로직을 한 번만 작성해두고 계속 재사용합니다.
    return itemName + " 결제 완료: " + amount + "원";
}

processPayment("커피", 4500);   // 재사용 1
processPayment("책", 15000);    // 재사용 2

    결제 내역이 여기에 표시됩니다.

    05. 데이터 타입 (Type): 구분

    컴퓨터가 데이터를 정확하게 다룰 수 있도록 값의 종류를 분류하는 기준입니다. '123'이 덧셈이 가능한 숫자(Number)인지, 화면에 보여줄 텍스트(String)인지, 맞다/틀리다를 나타내는 불리언(Boolean)인지를 구분합니다.

    typeof 123        // "number"
typeof "123"      // "string"
typeof true       // "boolean"

123 + 1           // 124        (숫자 덧셈)
"123" + 1         // "1231"     (문자열 이어붙이기)
